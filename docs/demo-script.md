# 不超过15分钟的演示讲解脚本

建议总时长13分钟。deliverables中的自动录屏用于展示实际系统；提交人可据此重录真人讲解、加入姓名学号和小组分工。演示必须包括浏览器实际操作，不能只播放PPT。

| 时间 | 展示 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:50 | 首页与移动端截图 | 生鲜场景、目标用户、6分类24商品、独立鲜境品牌 |
| 0:50–2:30 | 搜索→详情→购物车→地址→下单 | 规格/产地/储存、服务端金额、配送时段与订单快照 |
| 2:30–3:30 | 订单沙箱支付、重复操作 | 不产生真实扣款，付款只记一次，15分钟超时释放库存 |
| 3:30–5:00 | 仓库账号拣货→配送；会员收货→评价 | 状态机、角色职责、所有权校验 |
| 5:00–6:20 | 客服审核退款；财务重复结算 | 生鲜已配送不回库存，售后冻结结算，重复批次跳过 |
| 6:20–7:10 | 仓库请求用户管理403、会员后台拦截 | 服务端RBAC与前端菜单都生效，旧JWT权限即时撤销 |
| 7:10–8:40 | 架构图、ER、核心代码 | Controller→Service→Repository，条件扣库存、行锁、唯一约束 |
| 8:40–9:40 | Outbox及消息 | 同事务事件、确认发布、消费去重、死信队列、失败重连 |
| 9:40–11:00 | 自动测试输出、E2E截图、HTTP测量 | 库存竞争、事务回滚、幂等、越权；短测量不能当生产SLA |
| 11:00–12:10 | Compose与监控、健康与指标 | 配置分离、容器依赖、QPS/p95/错误率、备份和镜像回滚 |
| 12:10–13:00 | AI记录与复现步骤 | 真实Prompt、采纳理由、失败修正、锁文件；边界与后续改进 |

## 可复现异常演示

1. 用warehouse请求GET `/api/admin/users`，应返回403且含traceId。
2. 同一Idempotency-Key重复POST `/api/orders`，返回原订单；修改请求内容仍使用同key，返回409。
3. 同订单两次沙箱付款，只生成一笔payment与一次sales增长。
4. 测试中把最后3件库存同时交给两个会员争抢，只有一单成功，其余409，库存不会负数。
5. 售后pending时仓库尝试下一状态，返回409；finance结算跳过该单。

录屏中的讲解字幕由自动化脚本覆盖在浏览器画面上，属于录制说明，不是商城产品界面功能。实际CI执行、恢复演练、真实支付和真人小组签名不得虚构。
